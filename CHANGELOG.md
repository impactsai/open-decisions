# Changelog

## 0.3.0-draft.1 — UDID schema candidate, 2026-09-21

Adds the optional `udid/2.0.0-draft.1` processed-record and extension-info schemas,
fictional valid/invalid examples, an offline record checker, and all 13 source
Appendix C vector plans for M1. RFC 0005 records source clarifications, unresolved
digest/disclosure and settlement proof semantics, and pending owner review.
Core and comparison wire contracts are unchanged. This is not a frozen release,
cryptographic verifier, registered extension, or independent interoperability result.

## 0.1.0-draft.1 — initial working draft, 2026-09-20

Proposes portable protocol, request, evaluation, decision, action, authorization,
execution, and settlement records. Adds two executable profiles, canonical JSON
digests, schema/semantic validation, deterministic replay, synthetic fixtures,
conformance tests, CI, and community contribution/governance documents.

This is not a published stable release. No independent interoperability result,
live integration, signature verification, or community ratification is claimed.
