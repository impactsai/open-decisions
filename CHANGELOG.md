# Changelog

## 0.1.0-draft.1 — initial working draft, 2026-09-20

Proposes portable protocol, request, evaluation, decision, action, authorization,
execution, and settlement records. Adds two executable profiles, canonical JSON
digests, schema/semantic validation, deterministic replay, synthetic fixtures,
conformance tests, CI, and community contribution/governance documents.

This is not a published stable release. No independent interoperability result,
live integration, signature verification, or community ratification is claimed.

## 0.3.0-draft.1 — Decision Evals

- Add independently versioned Decision Evals schemas, generated types, portable validation, grouped metrics, exact PAV/normalized categorical calibration, model cards, release preflight and confidence applications.
- Add an explicit calibrated comparison adapter, offline CLI, fictional release fixtures and RFC 0004.
- Preserve previous core/comparison versions. Community review and independently labelled pilot validation remain release gates.
