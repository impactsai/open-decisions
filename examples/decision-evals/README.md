# Fictional Decision Evals release

`fictional-kit.json` is a self-contained conformance bundle; `model-card.json` is the mandatory kit card copied from it. All labels, models and evidence are fictional. Every configuration is **insufficient** and permits **experimental** use only. Numbers demonstrate implementation behavior and do not measure any real model or population.

Run `npm run evals:validate -- examples/decision-evals/fictional-kit.json` from the repository root. Regenerate with `node tools/build-evals-example.mjs`. Validation is offline and performs no provider, identity, wallet, execution or settlement operation.
